# Güvenlik bildirimi

Güvenlik açığı, erişim anahtarı sızıntısı veya kişisel veri ifşası için herkese açık issue oluşturmayın.

GitHub deposunun **Security → Advisories → Report a vulnerability** seçeneğinden özel bildirim gönderin:

https://github.com/ErdemYy/sehir-nabiz/security/advisories/new

Etkilenen bileşeni, tekrar üretme adımlarını, olası etkiyi ve varsa önerilen düzeltmeyi ekleyin. Gerçek kullanıcı verilerini veya çalışan erişim anahtarlarını rapora koymayın.

Proje geliştirme aşamasındadır. Güvenlik düzeltmeleri güncel varsayılan dal üzerinde ele alınır; eski sürümler için ayrı destek veya yanıt süresi taahhüdü verilmez.
